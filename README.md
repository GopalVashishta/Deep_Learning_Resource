# Deep Learning Study Materials

This folder contains resources for learning Deep Learning (DL).

- PDF files contain theory and conceptual explanations.
- Jupyter Notebook files (`.ipynb`) contain code and practice work.
- `tensorFlow_001.ipynb` includes basic TensorFlow practice.
- `pytorch_001.ipynb` includes basic PyTorch practice.
- Additional PDFs cover :
Optimization algorithms, 
Supervised learning, 
Unsupervised learning, 
NLP, 
Computer Vision
